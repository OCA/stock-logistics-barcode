1. Navigate to a Sales Order.
2. Press the button in the header with the QR Code icon.
3. Use a barcode scanner to scan a barcode.

Alternatively:
1. Navigate to a Sales Order.
2. Activate "Edit Mode".
3. Use a barcode scanner to scan a barcode.

If a product is found using the barcode, a new line with that product
will be added to the Sales Order.

By default, each product scan adds a new line to the sales order.
However, you can change this behavior in the sales settings.

To have the system increase the quantity of an existing product line
instead of creating a new one, follow these steps:

1. Go to the Sales Settings section.
2. Locate the option labeled
   "Increase quantity instead of creating a new line".
3. Check the box to activate this option and save the settings.
