Configure a compatible keyboard-wedge scanner to send its multiline
contents quickly enough to stay within Odoo's barcode scanner timing
threshold.

Scan the code in a barcode-enabled Odoo view. Embedded Enter and Tab
keys are kept as line feeds and tab characters. A final scanner suffix
is ignored.

To try the demo wizard, load demo data and open **Settings \> Barcode
multiline demo**. Production users do not need to load demo data.
